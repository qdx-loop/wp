# CSS Grid 布局完全指南

CSS Grid 是一个二维布局系统，可以同时处理行和列。

## 创建网格

```css
.container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  gap: 20px;
}
```

## 总结

CSS Grid 是现代网页布局的首选方案。

# Complete Guide to CSS Grid Layout

CSS Grid is a two-dimensional layout system that can handle both rows and columns.

## Creating a Grid

```css
.container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  gap: 20px;
}
```

## Summary

CSS Grid is the preferred solution for modern web layouts.
